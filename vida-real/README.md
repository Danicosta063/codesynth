# Vida Real

Mod para Minecraft Java 1.21.11 com Fabric.

## Versao
0.0.1

## Objetivo
Criar um mundo vivo com NPCs, cidades,
economia, construcoes e sociedades independentes.

## Estado atual
Estrutura inicial do mod.

## Desenvolvimento
Java 21
Fabric
Gradle
GitHub Actions

## Proximas funcionalidades
- Chave da Prefeitura
- Bloco da Prefeitura
- Fundacao da vila
- NPCs iniciais
- Centro de Construcao
